- The `.github/workflows/atcr.yml` that `atcr quickstart` scaffolds now writes the registry quickstart created to the runner's `~/.config/atcr/registry.yaml` before it reviews. Before, a fresh runner had no user registry and `atcr review` exited 2 with `registry not found`. Regenerate an existing workflow with `atcr quickstart --force`, or add the step by hand. The README and GitHub Action examples now copy a committed registry into place too. (epic 114)
