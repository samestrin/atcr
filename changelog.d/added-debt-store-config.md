- The local technical-debt store can live outside `.atcr/debt` through a new `debt.store` key in `.atcr/config.yaml` or `~/.config/atcr/registry.yaml`, so it can be a sibling private planning repo shared by several checkouts. Resolution is `--store` > project config > user registry > `<repo>/.atcr/debt`, and one resolver is used by debt commands, `atcr reconcile`'s persistence, the quality-signal payload and the next-step suggestions. A committed project value must be a clean repo-relative path that stays inside the repository once symlinks are followed; only the user registry or `--store` may name an absolute path or one containing `..`. An invalid setting is an error rather than a silent fall back, a blank value counts as unset, and the shared team registry (`ATCR_REGISTRY_URL`) is ignored for this key. (epic 92)
