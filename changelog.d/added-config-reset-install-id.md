- `atcr config reset-install-id` removes the quality signal's anonymous install ID. The ID is a random 128-bit value stored per user in `~/.config/atcr/install_id` (mode 0600). It is made only on the first opted-in quality-signal run, which prints a one-time notice on stderr naming the ID and the reset command. No ID is made while the signal is off, and the ID is not sent yet. (epic 109)
