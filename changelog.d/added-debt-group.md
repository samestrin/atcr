- `atcr debt group` groups the open debt items as `llm-support group-td` did: by directory prefix (`--group-by path`, `--path-depth`, default 2), by category or by exact file, with themes smaller than `--min-group-size` (default 3) left ungrouped and every CRITICAL item in its own group. It emits `{groups, ungrouped, summary}` as JSON or, with `--axi`, as TOON. It is read-only: the grouping is computed on each run, never stored. (epic 94)
