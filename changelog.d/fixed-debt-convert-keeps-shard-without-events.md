- Finishing an interrupted debt store conversion no longer removes a month shard whose records have no event file. A conversion journal that arrived without its staged events (a partial `git add`, a merge that kept it, a synced shared store) used to make the next `atcr debt list` delete every shard it named and lose their records; now no shard is removed, the error names the missing events, and removing `<store>/.convert/` abandons the conversion so `atcr debt convert` can run again.
