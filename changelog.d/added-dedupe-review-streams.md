- `atcr dedupe --streams <paths>` merges N reviewer `td-stream` files into one `{merged, summary}` payload of location clusters before a model adjudicates them: it reuses the `reconcile` library to cluster by file and line within `--tolerance` (default 3) and merge each cluster (REVIEWERS union, SEVERITY max with a `<lo> vs <hi>` disagreement, CATEGORY modal, EST_MINUTES max, PROBLEM/FIX pooled with ` // `, CONFIDENCE `HIGH` for two or more reviewers, `LOW` when every row comes from an `--untrusted` source, else `MEDIUM`), and flags every cluster of two or more `needs_review` with each member's own values so the "same issue?" call stays with the model. It reads `atcr-findings/v1`/`v2`, a `# Format:` column declaration, or a headerless 5/6/8/10-column stream, writes nothing, and prints exactly the JSON keys `llm-support td-dedupe` did, which it replaces for the `reconcile-code-review` cadence skill. `atcr reconcile` remains the command for atcr's own review directories.
