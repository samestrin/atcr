- The debt store no longer writes `items/.gitignore` through a symlink. In a shared store a repository-supplied `items/.gitignore` that was a dangling symlink made the next event write create a file at the link's target outside the store, and `atcr debt convert` truncated an existing target. Event writes now leave a symlinked or non-regular ignore file alone, opting a store in to the event layout refuses one with an error, and an existing ignore file is never rewritten. A bulk append also sweeps `items/` for crash leftovers once per store-lock hold instead of once per record (epic 122 F2).
