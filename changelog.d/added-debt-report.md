- `atcr debt report --format md` writes every item in the local debt store as a Markdown report, one table per README section (newest first) with items from no section last, marked as generated. `--output <file>` writes a file and refuses to overwrite one the report did not generate; `--check` fails with exit 4 when that file is out of date. A rerun on an unchanged store is byte-identical. (epic 95)
