- The next steps atcr suggests no longer point at a command that exits 2. A resume suggested for a review of an explicit range (by `atcr status`, a failed `atcr review` and the interrupt notice) now carries the recorded range, `--base=<sha> --head=<sha>` or `--merge-commit=<sha>`, and a resume whose range no longer matches names that range to re-pass instead of only saying to start a fresh review. A review that ran and then failed (every agent failed, or its `--fail-on` gate tripped) now ends with its `help[]` block or `Next:` lines too: `atcr status <id>` and the resume for a failed review, `report` and `verify` for a tripped gate. Bare `atcr --axi` offers `atcr report <id>` only when the latest review has reconciled data, so a first run gets `help[1]: atcr review`.
