- `atcr debt locks` no longer fails the whole listing when one ref under `refs/atcr/debt-locks/` is bad. A malformed ref name, or a tag that cannot be read or records a different id, is now shown as a warning alongside every valid lock, in both the human output and `--json` (new `warnings` field, an empty list when nothing is wrong), so one bad ref never hides every other lock. `atcr debt lock` and `atcr debt unlock` still refuse a lock they cannot read.
