- `atcr debt convert` moves a store from month shards to the one-file-per-item layout. It is one way and checked rather than assumed: the store is folded before and after, no shard is removed unless every item folds identically, and a shard it cannot carry across whole is left in place and named with the reason, as is a `.jsonl` file that is not a month shard. `--dry-run` reports the same plan and writes nothing, a crash is finished by running it again, and `atcr debt compact` first is the remedy for the one thing the event layout cannot preserve, a same-timestamp tie whose order decides the fold.
