- A `debt.store` set in the committed `.atcr/config.yaml` is now checked again, when the store is about to be written, for still being inside the repository once symlinks are followed. A link swapped into the store path after the store was resolved used to carry the write out of the repository; the write is now refused with "resolves outside the repository through a symlink". A store set in `~/.config/atcr/registry.yaml` or with `--store` is not affected (epic 122).
