- On macOS, a sandboxed run with loopback ports no longer treats a held-port probe that timed out at one of the host's own LAN addresses as "port free". A firewall in stealth mode that drops connects to that address used to let the check pass; the run is now refused with "could not check whether the requested loopback ports are free on the host". Only a zone-suffixed IPv6 link-local address (such as a VPN's utun0) is still let through on a timeout, and it is now probed once per check rather than once per port, saving 500 ms per extra port (epic 120).
