- An opt-in one-file-per-item layout for the local technical-debt store, so two clones can add and resolve debt and merge with no git conflict. Each add and each resolution becomes its own file under `.atcr/debt/items/`, named from the finding id, the event's timestamp and a hash of its contents, and every event is kept as history. A new store keeps month shards, so a standalone user sees no change, and a clone of a converted store is converted too. `atcr debt compact` never rewrites, moves or removes event files, so on an event-only store it reports a successful no-op instead of folding.
