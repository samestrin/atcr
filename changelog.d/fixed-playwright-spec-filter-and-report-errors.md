- The Playwright visual-verification backend now runs only the spec it was given: the spec path is passed to `playwright test` escaped and anchored, so a path with regex characters (`+`, `(`, `[`, …) no longer selects other spec files or misses itself. A `report.json` cut at the sandbox's 4 MiB collect cap now fails with a `report truncated` error instead of a JSON parse error, and a run that fails before any test loads (a config or spec that does not compile, a global setup that throws) now fails with Playwright's own error messages instead of reading as a clean run with no tests.
