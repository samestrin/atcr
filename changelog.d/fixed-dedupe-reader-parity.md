- `atcr dedupe` reads streams the way `atcr reconcile` does: a version header after a leading comment line is honoured instead of falling back to a legacy read with a warning, a prose line no longer counts in `summary.skipped`, and a row whose width matches no layout (or exceeds its `# Format:` columns) counts in `summary.skipped` instead of being read with shifted fields.
