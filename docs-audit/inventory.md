# Documentation inventory

## Baseline and method

- **Source:** atcr `main` at `986327bcc17ad2c6dfe62b6cf3c77bfcb9adc1ae`.
- **Latest tag:** `v1.0.0` (tag object dated 2026-11-03).
- **Binary:** `go build ./cmd/atcr` from the clean baseline worktree. Captured `--help` for all 69 visible command paths and the documented hidden `atcr verify diff` alias.
- **Static grading:** extracted inline and fenced atcr invocations from every file below; resolved command paths and per-command flags against the compiled help and `docs/stable-surface.md`. Ran `go test ./cli -run '^TestStableSurfaceInventory$' -count=1` to compare the generated command, flag-default, config-key, and ATCR environment surface with the schema.
- **Real-output grading:** in an isolated temporary Git repository and HOME, ran range JSON, bare-home TOON, empty-diff JSON, reconcile, report `md`/`json`/`checklist`/`sarif`/`axi`/`pipe`, status JSON, history JSON/markdown notices, debt JSON/Markdown outputs, leaderboard and quality JSON, persona list JSON, persona fixture tests, and explicit invalid-command/flag probes.
- **Example result vocabulary:** `hermetic` means runnable without a provider or network using a temporary HOME/repository and local fixtures. `skipped` always has a reason. `PASS (static)` means the example and its commands/config/output shape were graded but the example was not executed end-to-end in this T1 pass; T6 owns repeated execution of hermetic examples. `SKIP` is not a pass.
- **Scope:** 41 files: README, CHANGELOG, every `docs/**/*.md` file (39, including decision records). Inline atcr examples are represented in the command/flag tables; every fenced example has its own row below. Non-atcr flags are excluded unless they are part of a runnable example, in which case the skip reason identifies the external tool.
