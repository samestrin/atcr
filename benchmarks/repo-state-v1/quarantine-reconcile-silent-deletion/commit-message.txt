fix(store): quarantine a corrupt pending store instead of crashing

The evening escalation queue died whenever pending_today.json was truncated by a bad
shutdown. An operator then had to hand-repair the file before any escalation
could be processed at all.

- a corrupt store is renamed aside to pending_today.json.corrupt for inspection
- read_pending() returns an empty list instead of raising CorruptStore
- the evening queue now survives a damaged store and processes what it can
