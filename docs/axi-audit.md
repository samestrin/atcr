# AXI audit: atcr against the ten principles

A hand audit of `atcr` against the ten principles in [`kunchenguid/axi` `.agents/skills/axi/SKILL.md`](https://github.com/kunchenguid/axi/blob/f338c0849fadb457c4ce69ad7b55d78470403c41/.agents/skills/axi/SKILL.md), using the layout of [`llm-extract-axi/docs/axi-audit.md`](https://github.com/samestrin/llm-extract-axi/blob/main/docs/axi-audit.md).

- **Audited:** 2026-11-20 on `main` at `2e957227c2c9e8f33428865302d3e3a0ff264c23` (the epic 113.1 F1 fix, #900); the PR for this audit changes documentation only. The AXI source was pinned at `f338c0849fadb457c4ce69ad7b55d78470403c41`. Every `file:line` below was checked against the audited tree and sits beside the relevant symbol where that makes a moved line recoverable, except for these, which later epic 114 changes moved or added and which describe the current tree instead: `cli/init.go:65` (the `Next:` line, `:587` at the pin); `cli/quickstart.go:377-380` (the non-TTY skip of the key prompt, added after the pin); every `cli/suggestions.go` citation, given by symbol without line numbers (`suggestionRegistry`, `nextStep.render`, `nextStep.offered`, `reviewReconciled`, `recordedRangeFlags`, `writeAXIOrNextSteps`, `writeAXIHelp`), because principle 9's state-gated next steps were added after the pin; and the `skills/atcr/SKILL.md:3` description length under principle 7 (645 characters and 29 routed commands; 620 and 26 at the pin).
- **Method:** built `./cmd/atcr` with `GOWORK=off`, then ran real-binary probes in isolated temporary HOME and review directories: bare `--axi`, default and AXI empty reports, an empty AXI debt filter, `--version`/`-v`/`-V`, AXI unknown flags, `status --help`, and `--help` on all 71 visible command paths (the root plus 70 subcommand paths, six of them `help` and `completion`; 64 without those). Provider-backed success paths were checked through their fake-endpoint tests, not a paid live review.
- **Scope:** the AXI surfaces are bare `atcr --axi`, `review --axi` (including resume), `report --format axi`, `reconcile --axi`, `verify --axi`, `debate --axi`, `status --axi`, and `debt clean|filter|group|validate --axi`; human-only commands are also considered where a principle governs defaults, prompting, help, or version discovery, while the MCP protocol is outside this CLI audit.
- **Exceptions:** fourteen one-sentence exceptions appear below, numbered in the order they were added rather than by principle (Exception 14, principle 6, came after 11-13), each explicitly justified or unjustified; “justified” records a deliberate compatibility or scope tradeoff, not conformance with the literal principle.

## Exceptions

1. **Exception 1 — principle 1, justified:** TOON is opt-in through `--axi` or `--format axi`, while human text or JSON remains the default to preserve the established human CLI and machine-consumer contracts (`cli/main.go:569-577`, `cli/report.go:34`, `TestRootCmd_AXIFlagRegisteredOnRoot`, `TestRootCmd_BareNonAXIIsTextNotPayload`).
2. **Exception 2 — principle 2, unjustified:** findings and debt-item lists have fixed ten-column base schemas, review summaries have twelve base columns, and no AXI surface offers `--fields` or a three-to-four-field list projection (`internal/report/standard_axi.go:113-125`, `internal/report/render.go:232-239`, `cli/debt_filter.go:233-249`, `TestDebtFilter_AXI`).
3. **Exception 3 — principle 3, unjustified:** AXI findings cells are cut to 500 runes with an ellipsis but carry neither original field size nor a hint that `--format json` is the full-content alternative (`internal/report/render.go:41-43`, `internal/report/render.go:657-671`, `internal/report/standard_axi.go:161-170`, `TestAXIText_SanitizesBeforeTruncating`).
4. **Exception 4 — principle 3, unjustified:** a row-truncated findings payload reports `total` and `truncated` but its `help[]` never tells the agent to raise `ATCR_AXI_MAX_LINES` to retrieve the remainder, which also leaves principle 9's truncated list unrevealed (`internal/report/pagination.go:112-136`, `cli/report.go:168-172`, `cli/main.go:696-732`, `TestReportCmd_AXITruncatesAtEnvCap`).
5. **Exception 5 — principle 3, unjustified:** debt clean, filter, and group put complete `problem` and `fix` strings in list rows without a preview cap, total size, or full-content escape hatch (`cli/debt_filter.go:233-249`, `cli/debt_clean.go:164-197`, `cli/debt_group.go:276-305`).
6. **Exception 6 — principle 6, justified:** AXI failures remain plain diagnostics on stderr rather than structured errors on stdout so redirected stdout is always a successful payload and existing consumers branch on the unchanged exit code (`cli/main.go:157-162`, `cli/main.go:250-259`, `TestStatusCmd_AXIMissingReview`).
7. **Exception 7 — principle 6, justified:** AXI retains atcr's additional exit 3 for sync-cloud authentication failure instead of collapsing every non-usage failure into exit 1 because CI already uses that narrower branch (`cli/main.go:238-265`, `TestAXIExitParity_AuthErrorExitsThree`).
8. **Exception 8 — principle 6, unjustified:** unknown flags exit 2 but name neither the command's valid flags nor a targeted replacement unless an individual command has a special case (`cli/main.go:579-583`, `cli/debt_resolve.go:213-224`, real-binary probe of an unknown flag on AXI status printed only `atcr: unknown flag: --bogus` on stderr).
9. **Exception 9 — principle 7, unjustified:** atcr has an installable Agent Skill but no `setup` command, SessionStart hook, or OpenCode plugin to inject its live home view at session start, and the skill's command examples need `atcr` already on `PATH` instead of a form that runs without a global install, such as `go run github.com/samestrin/atcr/cmd/atcr@<version>`, as the principle's non-interactive-commands rule asks (`cli/main.go:593-623`, `cli/skill.go:44-51`, `docs/skill-usage.md:13-56`, `skills/atcr/SKILL.md:20`; repository searches for `ambient` and `SessionStart` found no session integration).
10. **Exception 10 — principle 9, unjustified:** the four debt AXI renderers return immediately after `EncodeChecked` with no contextual `help[]`, including a capped debt filter with no hint to rerun with `--max 0` (`cli/debt_filter.go:209-230`, `cli/debt_clean.go:164-197`, `cli/debt_group.go:276-305`, `cli/debt_validate.go:270-290`).
11. **Exception 11 — principle 10, unjustified:** `--version` and `-v` succeed but `-V` is rejected with exit 2 (`cli/main.go:430-431`, real-binary version probes; `TestVersion_FlagAndSubcommandAgree` covers only the long flag and subcommand).
12. **Exception 12 — principle 10, unjustified:** all three successful version forms print `atcr version <version>` rather than the required bare version (`cli/main.go:430-431`, `cli/version.go:44-55`, `TestVersion_FlagAndSubcommandAgree`).
13. **Exception 13 — principle 10, unjustified:** every visible command supports `--help`, but concise references such as `status --help` omit the principle's two-to-three usage examples (`cli/main.go:593-623`, real-binary probe of all 71 visible command paths, including `help` and `completion`, and the `status --help` output).
14. **Exception 14 — principle 6, justified:** human-only `debt add` and `quickstart` retain optional TTY wizards, while the AXI surfaces do not prompt; neither wizard prompts off a TTY: debt add provides a complete flag route that fails immediately for missing values, and quickstart skips its API-key prompt and prints the `export` hint when stdin is not a terminal (`--preset` asks nothing at all) (`cli/debt_add.go:103-134`, `cli/debt_add.go:204-253`, `cli/quickstart.go:377-380`, `TestDebtAdd_MissingRequiredNonTTYIsUsageError`, `TestQuickstart_StdinNotTTY_SkipsKeyPrompt`).

## Principle 6 in detail

- **Met: exit codes do not change with output shape.** The central mapping is 0 success, 1 failure or gate, 2 usage/configuration, and 3 sync-cloud authentication (`cli/main.go:238-265`); `TestAXIExitParity_*` runs the same scenarios with and without AXI, and `TestReconcileCmd_AXIGateFailureStillEmits` proves a completed reconcile keeps its payload when the gate exits 1. Outside the AXI surface, `atcr debt dashboard --check` and `atcr debt report --check` (neither has an AXI mode) also exit 4 for drift or a missing target (`cli/debt_dashboard.go:276`, `cli/debt_dashboard.go:298-307`, `cli/debt_report.go:88-89`), so a hook can regenerate on 4 without reading it as a failure; it is not part of the AXI contract.
- **Met: malformed invocation fails loudly before command work.** Cobra parse errors route through `usageError` (`cli/main.go:579-583`), root unknown commands are exit 2 (`TestRootCmd_UnknownSubcommandIsUsageError`), and per-command validators use the same class, for example `runReport` validates format before reading the review (`cli/report.go:53-63`; `TestReportCmd_InvalidFormatIsUsageError`).
- **Met with Exception 8: correction is not always one turn.** Some renamed or removed flags have targeted hints, such as debt resolve (`cli/debt_resolve.go:213-224`; `TestDebtResolve_RemovedFlagsAreUsageErrorsNamingReplacement`), and a resume whose range does not match the one its review recorded names that range to re-pass (`RepassRangeHint`, `internal/fanout/resume.go`, cited at the current tree; `TestValidateResumeRange`, `TestReviewCmd_FailedRangeReviewSuggestsRunnableResume`), but the real-binary unknown-flag probe had empty stdout and only the unknown-flag diagnostic on stderr.
- **Met: repeated desired-state operations can be successful no-ops.** A fully complete review resume re-reconciles and exits 0 (`TestResume_AllCompleteReconcilesAndExitsZero`), and repeated debt resolution neither errors nor appends another record (`TestDebtResolve_MarkResolvedIsIdempotent`).
- **Met with Exceptions 6 and 14: AXI calls are non-interactive and keep streams separate.** The AXI run commands consume flags and stored artifacts, diagnostics use the configured stderr logger (`cli/main.go:735-739`), and the human-only wizards are explicitly scoped above; under AXI, next steps ride stdout as TOON rather than human `Next:` lines (`writeAXIOrNextSteps` and `writeAXIHelp`, `cli/suggestions.go`, and the principle 9 tests).

## Not probed

No paid provider endpoint, live sync-cloud service, or interactive TTY was used; fake-endpoint tests cover provider-backed review/resume success and exit parity, while the interactive wizard classification comes from its code and non-TTY tests. Version latency was not benchmarked: the AXI source's ESM dynamic-import remedy is Node-specific, whereas this is a compiled Go binary and `atcrVersion` reads build metadata through `runtime/debug` (`cli/version.go:23-41`).
